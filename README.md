# SDD Terminal

SDD Terminal is a terminal-inspired web interface designed to help you structure and generate software project documentation in a guided way.

With it, you can organize:
- project overview;
- functional and non-functional requirements;
- architecture and tech stack;
- AI agents and automations;
- rules, commands, and workflow.

At the end, the project generates ready-to-use files for your repository, such as `CLAUDE.md`, `SPEC.md`, `PLAN.md`, `AGENTS.md`, and `RULES.md`.

## Highlights
- Retro terminal-style interface.
- Step-by-step guided workflow.
- Dynamic content editing.
- Real-time preview of generated files.
- JSON export and import for project progress.

## Goal
To centralize project context and make it easier to create consistent technical documentation for AI-assisted development.
